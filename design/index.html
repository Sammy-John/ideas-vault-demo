A lightweight capture tool for ideas.

Capture anything fast as a Note, promote it into a Seed, then move it into your future systems (blog, learning, projects, products).

Deploy your own See screenshots

Built with Vanilla HTML/CSS/JS + Vercel Functions + Supabase.

System model
  • Notes — capture links, bookmarks, quick context
  • Seeds — tag + add a seed note for future use
  • Future — promote into other compartments later

Features

Capture-first

Fast input for links + context. No over-structuring up front.

Notes & Seeds

Separate views, with seed-only metadata like tags and seed notes.

Mobile-friendly

Comfortable capture on phone, full management on desktop.

Private by default

Server-side access to Supabase with a simple vault key gate.

Deploy your own

This repo is intended to be cloned and deployed. Setup instructions will live in DEPLOY.md.

  1. Create a Supabase project + table.
  2. Deploy to Vercel.
  3. Add environment variables (SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, VAULT_KEY).
  4. Open the app, set your key, and start capturing.
